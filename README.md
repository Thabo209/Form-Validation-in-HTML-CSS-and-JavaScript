# ✅ Form Validation System

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

A robust client-side form validation system with real-time feedback, regex-based field checks, password strength indicators, and accessible UX — all built without any frameworks or libraries.

---

## 🚀 Features

- **Real-time validation** — fields are validated as the user types
- **Visual feedback** — green/red borders and icons indicate valid/invalid state
- **Field-specific error messages** — clear, helpful guidance per input
- **Password strength meter** — three-level indicator (Weak / Medium / Strong)
- **Password visibility toggle** — show/hide password option
- **Smart submit button** — only enables when all fields pass validation
- **Form reset** after successful submission
- Fully responsive design

---

## 🔍 Validated Fields

| Field | Validation Rule |
|---|---|
| Name | Minimum 2 characters |
| Email | Regex format check |
| Phone | 10 digits (non-digits auto-removed) |
| Password | Min 8 chars, must include a number and special character |
| Confirm Password | Must match password field |

---

## 🛠️ Built With

- **HTML5** — Form structure and semantic markup
- **CSS3** — Animations, responsive layout, visual state indicators
- **JavaScript (Vanilla)** — Regex validation, DOM manipulation, event listeners
